# Website audit envelope

Read `docs/strategy/28-TEARDOWN-DELIVERY-SOP.md`, the relevant archetype
blueprint in `docs/strategy/21-ARCHETYPE-CONVERSION-BLUEPRINTS.md`, and the
pattern/anti-pattern cookbook before auditing.

Use the installed upstream `cro`, `copywriting`, and `analytics` references as
hypothesis helpers. Report no more than three observable findings, each with an
evidence URL. Separate observation from recommendation. Do not claim lost
revenue, guaranteed uplift, legal compliance, or client affiliation.

Output an `AuditRecord` with `human_review_required=true`. Do not send it.
