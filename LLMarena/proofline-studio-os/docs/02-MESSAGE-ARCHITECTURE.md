## The four building blocks (mandatory per page section)
**Claim → Evidence type → Mechanism → Next step**

| Block | Rule | Example (Precision direction, own site) |
|---|---|---|
| Claim | ≤12 words, specific outcome, no superlatives | "Find the three things costing you conversions." |
| Evidence type | exactly one of the four types | *Demonstrated method* (the published 3-point teardown structure) |
| Mechanism | why it works, in one sentence | "We check clarity, proof and path in that order — because that is the order visitors decide in." |
| Next step | one verb, one object, friction expectation | "Send a URL → get a teardown within 48 hours." |

## Evidence types (only these four are allowed)
1. **Demonstrated method** — we show the process/artefact itself (teardown structure, gates, budgets).
2. **Stated standard** — a documented standard we build to (WCAG 2.2 AA, CWV thresholds) with the receipt.
3. **Permissioned quote** — verbatim, with permission recorded in an approval record, plus how it was obtained.
4. **Labelled concept work** — clearly marked, never presented as client results.

Anything else ("industry-leading", "trusted by many", "10x your conversions") is a banned claim.

## Banned words and phrases
revolutionary · world-class · cutting-edge · best-in-class · guaranteed results/conversions/rankings · "we are GDPR compliant" · "fully accessible" · "trusted by 100+ companies" · "as seen in" · "AI-powered" (as a benefit without mechanism) · "limitless" · "unleash".

## Objection → answer map (reused across pages and sales)
| Objection | Where answered | Answer shape |
|---|---|---|
| "I'm not getting traffic yet." | Objections section + teardown offer | Message quality before traffic: a clear offer changes who refers you. |
| "Can I edit it later?" | Process section + offer table | CMS on tiers 2–3; on tier 1 we hand over the repo with a 30-min recording. |
| "Who owns it?" | About + handover page | You. Repo, hosting, domain, analytics in your name. We hold delegated access. |
| "Who writes the copy?" | Offer table | On tier 1 we edit your copy; tiers 2–3 include message architecture work. |
| "What if I don't like the direction?" | Process + design-direction brief | One signed direction before build; changes after sign-off are change requests. |
| "How do I know it's actually good?" | Proof-by-method section | Our gates are published: accessibility, performance budget, provenance, QA receipt. |
| "Isn't this just AI slop?" | Method section | Every design decision traces to a brief; no template ships un-retokenised. |

## Voice rules
Short sentences. Active voice. One idea per section. Numbers where numbers exist, honesty where they don't.
No exclamation marks. No emoji in client-facing copy. British/American spelling picked once per project and held.
