## Three asset classes, three labels
| Class | Label (visible, not in a footnote) | Rules |
|---|---|---|
| **Studio Concept** | "Studio Concept — independent demonstration, not client work." | Fictional brand only; no real trademarks, logos, product UI or customer names |
| **Redesign study** | "Independent redesign study — not affiliated with the referenced brand." | Only publicly visible design issues; no brand assets beyond fair reference; no inference that the brand approved or requested it |
| **Client work** | "Client work — published with permission (date)." | Written permission for the project *and* each logo/quote/metric; verbatim quotes; substantiation on file |

## Permission workflow
1. Ask once the project is live and performing — never mid-project.
2. Written request naming exactly what will be published (screens, text, logo, numbers, quote).
3. Record the permission in `templates/ai-asset-approval.md`-style approval record (or `schemas/approval-record.schema.json`).
4. Client can withdraw at any time → we unpublish within 5 working days.
5. No "implied" permission from being a happy customer, and no permission in exchange for a discount (that becomes a disclosure problem).

## Quote rules (EU: Omnibus Directive)
- Verbatim only. Length edits allowed with `[…]`; no meaning changes.
- State how the review was obtained ("client feedback, project completed <month>").
- No incentivised quotes without explicit disclosure ("received a discount" would be disclosed).
- Never fabricate, never use anonymous "a happy client said", never attribute an AI-generated sentence to a person.

## Metric rules
- Only numbers the client supplied or approved, with tool + window named ("Plausible, 90 days, before/after").
- No attribution of results we cannot observe (e.g., closed deals, revenue) without marking it as the client's own report.
- "Not measured" is an acceptable and respectable outcome — say it.

## Credibility rules for a studio with few or no paid clients
1. Publish **method receipts** (gates, budgets, provenance, accessibility statements) — these are real and verifiable.
2. Publish **concept work** with labels and full authorship disclosure.
3. Publish **your own site** as the first case study, including what you would do differently.
4. Never buy, invent or inflate proof — the Omnibus Directive bans it and our positioning depends on the opposite.
