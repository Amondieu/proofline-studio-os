# creative-direction

## Inputs
Audience + ICP · offer tone · existing brand assets (if any) · constraints (content, images, motion budget) · the client's own references.

## Procedure
1. **Pick one direction** using the selection rule in `docs/03` (Precision / Cinematic / Editorial). One — not three options.
2. **Write the direction brief** (`templates/design-direction-brief.md`): intent in 3 sentences, references (tagged), do-not-imitate list, imagery brief, motion budget, acceptance criteria.
3. **Fill the token contract** from `docs/03` — every token, no blanks. Run the contrast checks; fix tokens, never "adjust later".
4. **Reference discipline:** for each reference record URL, date, tag (layout/typography/hero/proof/CTA/motion/forms/pricing/navigation/footer/mobile/accessibility), what we take at pattern level, and what we explicitly do not take.
5. **Anti-generic check** (the studio's own standard): if you removed the logo, could this be any AI-generated site? If yes → change typography scale, grid rhythm and imagery treatment (not just colours).
6. **Get the founder's signature** before any build. Post-signature changes are change requests.

## Output
Direction brief + complete token set (`tokens.json`) + tagged reference log + contrast report + motion plan within budget.

## Refusal conditions
- "Make it look like <brand>" or any variant → refuse; offer pattern-level references instead. (Also a stop condition in MASTER-REPORT §11.)
- A direction would require >2 h of motion work on a Starter-tier budget → refuse or reduce scope.
- References require using assets we have no rights to (screenshots, logos, fonts) → substitute.

## Never
Never copy a brand's layout, copy, illustration style, mascot, logo or trade dress. Never ship a template un-retokenised. Never let a direction change IA, CTA wording or legal content.
