# conversion-copy

## Inputs
Client intake (`templates/client-intake.md`) · audience notes · any real evidence the client can substantiate · the page type.

## Procedure
1. **Extract the offer in one sentence**: who, outcome, mechanism, constraint. If it needs two sentences, the offer is unclear — say so before writing.
2. **Map objections** (top 5) using LIFT as the lens: value, relevance, clarity, anxiety, distraction, urgency.
3. **Fill `templates/message-map.md`**: for each section — claim (≤12 words), evidence type (one of four), mechanism (why it works), next step.
4. **Write the page in the fixed section order** from `MASTER-REPORT.md §5.2`. Do not invent sections.
5. **Sanity test:** read only the headlines top to bottom — do they form a complete argument? Then read only the CTAs — is there exactly one action repeated?
6. **Five-second test** the hero with ≥5 people: can they state the offer? <4/5 → rewrite the hero, not the subhead.
7. **Banned-word and claim audit** against `docs/02`.

## Output
The filled message map + section copy + a list of claims with their evidence type and where the substantiation lives.

## Refusal conditions
- No substantiation exists for a claim → the claim is deleted, not softened.
- Client asks for testimonials/logos/metrics they cannot evidence → refuse and propose method proof.
- Copy implies a guarantee (results, rankings, compliance) → refuse the wording.

## Never
Never write "we are GDPR compliant"/"fully accessible". Never invent numbers, quotes, awards or client names. Never describe synthetic imagery as real staff or customers.
