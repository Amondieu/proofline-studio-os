# Pattern allowlist — AI / Automation Authority

- outcome-qualified hero with one primary CTA;
- workflow-friction framing grounded in supplied context;
- mechanism/process sequence with inspectable artifacts;
- calm modular grid and explicit hierarchy;
- concept cards labelled beside the item;
- abstract visual with HTML copy separate;
- FAQ/objection handling that states unknowns honestly;
- interest-only teardown CTA with clear non-sending state.
