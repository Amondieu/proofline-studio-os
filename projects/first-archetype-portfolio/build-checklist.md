# Build checklist — first archetype portfolio

This checklist records implementation basis. A checked item means the
repository contains evidence for the concept surface; it does not mean a
production deployment exists.

## Build basis

- [x] Master site and focused archetype intent are documented.
- [x] Semantic page shell, skip link, primary navigation, and main landmark
      exist in `site/index.html`.
- [x] Three direction definitions and the local direction switcher exist.
- [x] Responsive and reduced-motion rules exist.
- [x] Concept and independent-redesign labels are visible on current work.
- [x] The local form explicitly states that no data is sent.
- [ ] Focused archetype page is separated from the multi-archetype master
      index.
- [ ] Production form endpoint, validation, notification, recovery, and spam
      handling exist.
- [ ] Reviewed legal routes and accessibility statement are published.
- [ ] Hosting, domain, account ownership, backup, and rollback are recorded.
- [ ] Analytics and consent are intentionally configured or explicitly omitted
      in the production decision.

## Build acceptance

`Concept build basis exists; production build remains blocked by the unchecked
external and human-gated items.`
