# First archetype portfolio preflight

This bundle prepares the first focused Proofline Studio portfolio surface for
the `ai-automation-authority` archetype. It is a studio-owned proof-of-work
project, not a client case study and not a production launch approval.

The bundle makes every pipeline stage inspectable:

`Discovery -> Message -> Direction -> Build -> QA -> Launch`

Files in this directory describe the basis for a human preflight. They do not
turn pending legal, business, rights, hosting, form, or approval decisions into
facts. The production gate remains blocked until those decisions are evidenced.

## Scope

- Primary audience: technical founders and consultancies selling complex AI or
  automation work.
- Primary proof: the studio's method, contracts, direction system, and QA
  discipline.
- Primary CTA: request an AI / Automation teardown, currently a local demo
  interaction only.
- Excluded: invented client results, testimonials, logos, paid checkout,
  tracking, credentials, and external publication.
