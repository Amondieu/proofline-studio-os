# Form and data-flow preflight

## Current state

The portfolio site's CTA is a local demonstration. The current implementation
does not send form data. This document is therefore a design/preflight map, not
a privacy notice and not consent language.

## Proposed fields — pending human and legal review

- Name — optional until a real intake route is approved.
- Email — required only if a response workflow is approved.
- Offer URL — optional context for the teardown.
- Main question or goal — optional free text; retention and access must be
  defined before collection.
