# QA receipt

Use one receipt per release. It records evidence for human review; it does not
approve, publish, or guarantee compliance or conversion results. The canonical
machine-readable contract is `schemas/studio/qa-receipt.v1.json`.

## Accessibility

- [ ] axe critical findings: `0`
- [ ] axe serious findings: `0`
- [ ] Keyboard sweep passed
- [ ] Focus is visible and not obscured
- [ ] Contrast verified for the selected direction
- [ ] Interactive targets are at least 24×24 CSS px
- [ ] Reduced-motion path verified
- [ ] Screen-reader spot check noted where relevant

## Performance

- LCP lab: `≤ 2.5 s`
- INP: `≤ 200 ms` when available
- CLS: `≤ 0.1`
- JavaScript: `≤ 60 KB` for the page budget
- Third-party scripts: `≤ 1`
- Field data available: yes / no
