# Prompy reference rule — prompt research boundary

Rule ID: `PROMPY-REF-001`

Status: `active / inspiration-only`

Prompy is a useful external gallery for discovering visual-prompt vocabulary,
composition hypotheses, and possible creative-direction questions. It is not a
source of production-approved prompts, design quality proof, rights clearance,
or universal best practice.

Reference source: [Prompy](https://www.prompy.me/)

## Allowed use

- browse Prompy manually or through an approved research session;
- record the source URL, access date, observed pattern, and limitation;
- abstract a design hypothesis in our own words;
- write an original Proofline prompt that is independently scoped, tested, and
  versioned;
- compare the original hypothesis against the Proofline visual/copy rubric.

## Prohibited use

- copying Prompy prompt text into the repository or a client deliverable;
- bulk mirroring, scraping, republishing, selling, or redistributing its prompt
  collection;
- treating a gallery entry, prompt popularity, or generated preview as evidence
  of conversion, accessibility, rights, or production quality;
- sending client data, confidential briefs, personal data, or unapproved brand
  assets to Prompy or any downstream creative tool;
- routing production work directly to Prompy as if it were our controlled vault.

Prompy's published terms state that its material is protected, generally
available for personal use, and may not be republished, copied, sold, or
redistributed. This repository therefore records Prompy as
`gallery_inspiration` / `inspiration_only`; the terms are not interpreted as a
commercial reuse licence. The terms can change and must be rechecked before a
new workflow relies on the source.

## Vault and router consequence

The source may influence a prompt hypothesis, but the prompt entering our vault
must be authored and versioned by Proofline. Its record should include:

- `inspired_by_source: src_prompy_visual_gallery`;
- an observation, not copied source text;
- transformation notes and a new prompt version;
- allowed inputs, exclusions, evaluation rubric, and status;
- human review before production use.

The router selects only prompts in the Proofline vault. Prompy is a research
input and never a runtime provider or production dependency.

## Promotion rule

```text
Prompy observation
  -> original hypothesis
  -> controlled variants
  -> rubric evaluation
  -> provenance / rights review
  -> human direction approval
  -> optional provider generation
```

No stage may skip directly from “gallery reference” to “production asset”.
