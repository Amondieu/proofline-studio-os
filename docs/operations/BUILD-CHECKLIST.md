- [ ] Domain and DNS ownership confirmed

- [ ] Responsive at 360 / 390 / 768 / 1024 / 1440px
- [ ] Navigation works
- [ ] Every CTA routes to the correct action
- [ ] Form validation and delivery tested
- [ ] Calendar or secondary flow tested
- [ ] Title, description, favicon, and Open Graph added
- [ ] Alt text reviewed
- [ ] Privacy and legal links present
- [ ] Analytics has lawful consent configuration
- [ ] Asset and likeness rights confirmed
- [ ] No copied competitor copy, imagery, logo, or likeness
- [ ] Backup/export supplied
- [ ] Client has admin access
