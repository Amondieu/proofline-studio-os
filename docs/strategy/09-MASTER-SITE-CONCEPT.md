# Master-site concept

The studio's own website is an interactive proof of work, not a theme gallery.
It keeps one information architecture and one conversion path while showing
three named creative systems.

## Core message

**Premium landing pages for offers that deserve to be understood.**

Proofline Studio turns complex AI, SaaS, and service offers into clear,
high-trust conversion systems — strategy, copy, design, and build in 7–14 days.

## Funnel

Primary CTA: **Get a 3-point landing page teardown**.

The teardown asks for a URL, contact, offer goal, and context. The internal
deliverable is a short audit, three concrete conversion leaks, and one example
hero direction. It is an analysis offer, not a promise of free consulting or a
guaranteed result.

Secondary CTA: **Explore the 10-day launch system**.

## Information architecture

Navigation → Hero → Credibility → Problem → System → Directions Lab → Selected
Work → Offers → Process → Standards → FAQ → Teardown → Footer.

The direction switcher changes tokens, art direction, motion, and selected
direction metadata. It does not change the core message, information
architecture, offer structure, or CTA flow.

## Portfolio truth rule

Every non-client example is labelled `Studio Concept — not commissioned client
work` or `Independent redesign study — no affiliation`. Client launches use
written permission and real, reviewable results. The site never uses anonymous
testimonials, invented logos, or fake conversion numbers.
