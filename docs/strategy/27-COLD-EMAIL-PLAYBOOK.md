# 27 — Cold-email playbook

## Message principles

The legitimate persuasive sequence is relevance → concrete observation → small
useful gift → lower-risk next step → autonomy. No pressure, false urgency,
deception, or implied guarantee.

## Message 1 — teardown

```text
Subject: A quick conversion observation on [Company]

Hi [Name],

I noticed [specific public trigger with source].

The offer looks relevant, but a first-time visitor currently has to work hard
to understand [specific factual observation]. I noted three possible fixes:

1. [Observed clarity gap]
2. [Observed trust or proof gap]
3. [Observed CTA, mobile, or message gap]

I recorded a short teardown with one suggested hero direction:
[private link]

I run fixed-scope landing-page sprints for [relevant ICP], covering message,
conversion copy, direction, build, and launch QA. Would a 15-minute fit check
be useful?

Best,
[Name] / [Company]
[transparent compliance footer]
```

Only send observations that are supported by public evidence and reviewed by a
human.

## Message 2 — soft follow-up

Send only if there is no opt-out and the first message was human-approved. Do
not send within 24 hours.

```text
Subject: Re: one landing-page observation for [Company]

Hi [Name],

Closing the loop on the short teardown. The highest-leverage fix may be
[one concise observation], because it would make [offer / buyer / action]
clearer before visitors reach the rest of the page.

If this is not a priority, no reply is needed. If plain-text notes are easier,
reply “notes”.

Best,
[Name]
[transparent compliance footer]
```

## Message 3 — permission-based close

```text
Subject: Should I close this out?

Hi [Name],

I have not heard back, so I will close this out after this message. The audit
is still available here: [link]. If it becomes useful later, reply “audit”.

If you would rather not receive messages from me, reply “no”. I will not
contact you again.

Best,
[Name]
[transparent compliance footer]
```

V1 limit: at most three messages in a 21–30 day sequence, then suppress unless
a human records a different decision after review. Every step is a draft until
the exact recipient and exact message are approved.
